## What the software does

It runs inside the user's own browser, on the user's own computer, and reads
pages that user has already opened while signed in to their own account. It
shows that user their own betting history back to them.

It does not:

- sign in, hold a password, or authenticate as anybody
- place a bet, deposit, or withdraw
- circumvent a paywall, a login, a rate limit or any technical protection
- run as a service, a bot or a farm; there is no server anywhere in it
- collect, transmit, sell or publish anybody's data — nothing leaves the machine
- republish or resell a bookmaker's odds, prices or content
- give tips, predictions, advice or any opinion about what to bet

Recorded test data in the repository is a sanitised copy of what a contributor's
own account returned, stripped of credentials and identity, kept only so the
parsing code can be proven to work.
